# Seeku Graph RAG 集成讨论稿

**致：** Codex 团队
**来自：** Seeku 项目组
**日期：** 2026-05-03
**主题：** 将 GraphTranslator/memU 技术集成到 Seeku 候选人搜索系统

---

## 背景

Seeku 是一个证据驱动的 AI 人才搜索引擎，当前主要数据源为 Bonjour.bio，已收录 22,497 位候选人。现有检索依赖全文搜索和向量相似度，但未利用 Bonjour 的社交关系图谱。

我们在 HireLoop 项目的 competition 文件夹中发现了两项相关技术：

1. **GraphTranslator**：将图模型嵌入对齐到 LLM 语言空间
2. **memU**：面向 AI 智能体的主动记忆系统

我们认为这两项技术可以显著增强 Seeku 的检索和推荐能力。

---

## 核心问题

### 问题 1：社交图信号未被利用

Bonjour 的 friend/friended 关系构成天然的社交图谱，但当前 Seeku 将候选人视为孤立个体，忽略了：
- 谁认识谁
- 社区结构
- 影响力传播

### 问题 2：推荐缺乏可解释性

当前向量检索返回相似候选人，但无法回答：
- "为什么推荐这个人？"
- "他们和谁有合作关系？"
- "他们在什么社区中？"

### 问题 3：用户偏好未被记忆

用户每次搜索都是独立的，系统无法：
- 记住用户的筛选偏好
- 学习用户的人才画像
- 主动推送符合条件的新候选人

---

## 提议方案

### 方案概述

```
当前架构：
  用户查询 → 向量检索 → 返回候选人列表

提议架构：
  用户查询 → Graph RAG + Vector RAG → 图增强的候选人列表 + 关系解释
                    ↓
              memU 记忆系统（偏好学习）
```

### 技术组件

| 组件 | 来源 | 作用 |
|------|------|------|
| GraphSAGE | 新实现 | 学习节点图嵌入 |
| GraphTranslator | competition 文件夹 | 图嵌入 → 自然语言描述 |
| memU | competition 文件夹 | 用户偏好记忆 |

---

## 讨论要点

### 1. 图嵌入训练策略

**问题**：如何训练图嵌入？

**选项**：
- A) 从零训练 GraphSAGE
- B) 使用预训练图模型微调
- C) 使用无监督图嵌入（Node2Vec, DeepWalk）

**倾向**：选项 A，因为 Bonjour 图有独特的社交属性

### 2. Translator 对齐数据

**问题**：如何生成（节点嵌入，文本描述）对？

**思路**：
- 使用 LLM 总结节点属性（bio, headline）
- 使用 LLM 总结邻居信息
- 使用 LLM 推断节点与邻居的共性

**需要讨论**：
- 使用哪个 LLM？（StepFun / SiliconFlow）
- 描述文本的长度和格式？

### 3. memU 集成范围

**问题**：memU 集成到什么程度？

**选项**：
- A) 仅用于用户偏好记忆
- B) 用于候选人画像记忆
- C) 完整集成（偏好 + 画像 + 主动推荐）

**倾向**：选项 A，渐进式集成

### 4. 技术栈选择

**问题**：图模型训练和推理用什么语言？

**选项**：
- A) Python 训练 + Python 推理（服务化）
- B) Python 训练 + TypeScript 推理（ONNX 导出）
- C) 全 TypeScript（使用 TensorFlow.js）

**倾向**：选项 A，与现有 Python 脚本生态一致
